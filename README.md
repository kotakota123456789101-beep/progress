# Wick 進行管理(パスワード付き公開版)

公開されている `index.html` は StatiCrypt で暗号化済みで、パスワードを入れた人だけが中身を読めます。

- `template.html` … ダッシュボードの見た目(データは含まない)
- `build.mjs` … データを埋め込み、暗号化した `index.html` を作るスクリプト
- `.staticrypt.json` … 暗号化のソルト(「ログインしたままにする」を維持するため固定)

毎晩20時(日本時間)に、日報から更新されたデータで自動的に作り直されます。

```
STATICRYPT_PASSWORD=******** node build.mjs <exportディレクトリ>
```

平文のデータやパスワードはこのリポジトリにコミットしないこと。
