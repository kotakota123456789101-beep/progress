# Wick 進行管理(パスワード付き公開版)

公開ページ:https://kotakota123456789101-beep.github.io/progress/

公開されている `index.html` は StatiCrypt で暗号化済みで、パスワードを入れた人だけが中身を読めます。
毎晩20時(日本時間)に、Teamsの日報から更新されたデータで自動的に作り直されます。

## ファイル

| ファイル | 中身 | 触ってよいか |
|---|---|---|
| `template.html` | ダッシュボードの見た目と表示ロジック(データは含まない) | ◯ 見た目を変えるときはここ |
| `build.mjs` | データを埋め込み、暗号化した `index.html` を作るスクリプト | ◯ 慎重に |
| `index.html` | 暗号化済みの公開ページ | ✕ 毎晩自動で上書きされる |
| `.staticrypt.json` | 暗号化のソルト | ✕ 変えると全員の「ログインしたまま」が切れる |

## タスクの状態や期限を直したいとき

このリポジトリは公開されているので、タスクの中身をここに書かないでください。
Teams「進行管理 › 独立チーム」に、1行1件で次のように投稿すると、その日の20時の更新で反映されます。

```
【修正】[受診めやすAI] 決済会社の選定 → 完了
【修正】[Wick Music] 図解アイコン 期限 11/15
【修正】[野球イベント] ロゴ作成 担当 小竹
【修正】[The CREATORS] 当日仕様の準備 削除
```

反映できなかった修正は、その日の日報サマリーに理由つきで載ります。

## 見た目を変えたいとき

1. `template.html` を編集する(色・文字は先頭の `:root` の変数でまとめて変えられます)
2. main に push する
3. その日の20時の更新から新しい見た目で公開されます

手元で確認したいときは、ダミーのデータを入れたフォルダを用意して実行します(本物のデータはリポジトリに入れない)。

```
STATICRYPT_PASSWORD=test node build.mjs <ダミーデータのフォルダ>
```

フォルダには `tasks/` `projects/` `days/` の下に `<id>.json` を置きます。各項目の形は `template.html` の描画処理を参照してください。
確認で作った `index.html` と `.staticrypt.json` の変更はコミットしないでください(`git checkout index.html .staticrypt.json` で戻せます)。

## やってはいけないこと

- データ(タスク名・日報の内容など)やパスワードをコミットする
- `.build/` をコミットする(平文のページが入ります)
- `.staticrypt.json` を消す・作り直す
